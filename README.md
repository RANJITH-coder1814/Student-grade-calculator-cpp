# Student Marks and Grade Calculator (C++)

This project is a simple C++ program that demonstrates **Object-Oriented Programming (OOP)** concepts such as classes, private data members, constructors, and member functions.

The program accepts student details and marks, calculates the **total marks**, and assigns a **grade** based on the average.

---

## 📌 Features
- Uses a `student` class
- Demonstrates **data encapsulation**
- Calculates total marks
- Assigns grades based on average marks

---

## 🧠 Grade Logic
- **A** → Average > 60  
- **B** → Average ≥ 40 and < 60  
- **C** → Average < 40  

---

## 🧾 Sample Input
Enter the roll number: 1
Enter the name: Ranjith
Enter the marks in three subjects: 70 65 60


## 📤 Sample Output


Total marks: 195
Grade of student: A
